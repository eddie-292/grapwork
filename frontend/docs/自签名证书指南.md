# Windows 自签名证书指南

## 快速开始

### 1. 生成自签名证书

以**管理员身份**运行 PowerShell，然后执行：

```powershell
cd d:\work_space\openchat\frontend
.\scripts\generate-certificate.ps1
```

这会：
- 创建自签名代码签名证书
- 将证书安装到当前用户的证书存储区
- 导出 PFX 文件（用于构建）
- 将证书添加到受信任的根证书颁发机构

### 2. 构建签名的应用

生成证书后，直接运行：

```bash
npm run electron:build:win
```

## 关于签名的说明

### 签名方式

项目支持两种签名方式：

1. **使用 signtool 签名**（推荐）
   - 需要安装 Windows SDK
   - 提供更可靠的签名和时间戳服务
   - 适合生产环境

2. **electron-builder 内置签名**（默认）
   - 无需额外安装工具
   - 适合开发和测试
   - 如果没有安装 Windows SDK，会自动使用此方式

### 如果没有安装 signtool

构建时会出现类似以下的提示（这是正常的）：

```
[签名] signtool 未安装，使用 electron-builder 内置签名
```

这**不是错误**，构建会正常完成。electron-builder 会使用证书文件直接对可执行文件进行签名。

## 安装 signtool（可选）

如果需要更专业的签名服务，可以安装 Windows SDK：

1. 下载 Windows SDK：https://developer.microsoft.com/windows/downloads/windows-10-sdk/
2. 安装时确保选择 "Windows SDK" 组件
3. 安装完成后，`signtool.exe` 会添加到系统 PATH

## 手动配置（可选）

如果自动签名不起作用，可以手动配置：

### 方法 A: 使用证书文件

在 `electron-builder.json` 中配置：

```json
"win": {
  "certificateFile": "build/certificates/grapework.pfx",
  "certificatePassword": "grapeWork2026"
}
```

### 方法 B: 使用证书指纹

1. 查看证书指纹：
```powershell
Get-ChildItem -Path Cert:\CurrentUser\My -CodeSigningCert | Where-Object { $_.Subject -like "*GrapWork*" }
```

2. 在 `electron-builder.json` 中使用 SHA1 指纹：
```json
"win": {
  "certificateSha1": "YOUR_CERTIFICATE_SHA1_FINGERPRINT"
}
```

## 常见问题

### "signtool 不是可识别的命令"

**这不是错误**。这是正常提示，表示系统没有安装 Windows SDK。

构建会正常完成，electron-builder 会使用内置的签名机制。

如果想使用 signtool 进行更专业的签名，可以安装 Windows SDK（见上文）。

### 证书不受信任

运行生成脚本时已自动将证书添加到受信任的根证书颁发机构。
如果仍有警告，可以手动：

1. 双击 `build/certificates/grapework.cer`
2. 选择"安装证书"
3. 选择"本地计算机"
4. 选择"将所有的证书都放入下列存储"
5. 点击"浏览"，选择"受信任的根证书颁发机构"
6. 完成安装

### 证书过期

重新运行生成脚本即可创建新证书。

## 证书信息

- **名称**: GrapWork
- **组织**: MirrorGrap
- **密码**: grapeWork2026
- **有效期**: 默认 1 年（从生成日期算起）
- **算法**: RSA 2048 位，SHA256

## 生产环境建议

自签名证书仅适用于开发和测试。发布给用户时，建议：

1. 购买受信任的代码签名证书（如 DigiCert、Sectigo 等）
2. 或使用 Microsoft EV 代码签名证书（可立即建立信誉）
3. 或使用 Azure Trusted Signing 服务

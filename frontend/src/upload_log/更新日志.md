## v0.2.0 (2026-02-17)

### 新功能

- **Skills 技能系统**: 领域知识包管理，支持注入自定义技能上下文到 AI 对话
  - 支持多种技能来源：用户创建、通过 npx 安装、系统内置、示例技能
  - SKILL.md 格式支持 YAML frontmatter (name, description, version, author, tags, triggers)
  - 技能可在设置中启用/禁用，自动注入到系统提示词

- **Workspace 工作区**: 文件浏览器功能
  - 支持浏览本地文件和文件夹
  - 面包屑导航、文件操作（创建、复制、移动、删除、重命名）
  - 文件内容搜索 (glob/grep)
  - Shell 命令执行

- **多标签页聊天**: 支持同时开启多个独立聊天会话
  - 标签页管理（新建、切换、关闭）
  - 每个标签页独立的聊天上下文

- **更新日志视图**: 应用更新时显示版本变更内容

### 改进

- 优化设置页面，新增技能管理标签页
- 新增多个 UI 图标组件
- 任务模式体验优化

## v0.1.0 (2026-02-14)

- 支持任何 OpenAI 兼容的 LLM API 接口
- 持久化全局记忆，自动注入用户偏好和自定义上下文
- 自定义 AI 助手和系统提示词管理
- Model Context Protocol (MCP) 集成，支持 STDIO/SSE 传输方式
- 可插拔存储后端 (LocalStorage, FileSystem, HTTP)
- 多种代码高亮主题
- 环境依赖检测
